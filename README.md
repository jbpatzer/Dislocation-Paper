# Dislocation Paper
Code for the paper 'Dislocation in the periodic steady states of the 1D nonlocal Fisher-KPP equation with top hat kernel: modulational and localised stability and instability', by D.J. Needham and J. Billingham.

There are five Matlab functions that calculate the basic quantities relevant to the paper:

- periodic.m - calculates the periodic solution, $F_p(x)$
- evs.m - calculates the eigenfunctions and eigenvalues, $\psi_i(x)$, $\chi_i(x)$, $\mu_i$
- Dbar.m - calculates $\bar{D}$
- Bloch.m - calculates the solutions of the Bloch eigenvalue problem, (LIVP)
- IVPsolver.m - solves the initial value problem (IVP)

These functions are documented in their comments.

# Dislocation Paper
Code for the paper 'Dislocation in the periodic structures associated with the 1D nonlocal Fisher-KPP equation with top hat kernel: modulational and localised stability and instability', by D.J. Needham and J. Billingham.

There are five pieces of code that calculate the basic quantities relevant to the paper.

- periodic.m - calculates the periodic solution, $F_p$
- evs.m - calculates the eigenfunctions and eigenvalues, $\psi_i$, $\chi_i$, $\mu_i$
- Dbar.m - calculates $\bar{D}$
- Bloch.m - calculates the solutions of the Bloch eigenvalue problem, (LIVP)
